# X6-R0 performance-fault design gate

X6-R0 is design-only after authoritative X5-R7. It defines F1 packet loss,
F2 high latency, F3 congestion, and F4 bandwidth/rate limiting with disjoint
six-feature signatures, declared traffic contexts, `tc` mutation ownership,
direct provenance, baseline thresholds, bounded effectiveness and idempotent
recovery. No runtime evidence, metric, dataset, model, API or generalized
performance claim is created. P9-R2 remains paused. Next: `X6_R1_PACKET_LOSS`.
